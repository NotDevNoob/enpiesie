# Gradient Chat

A Minecraft Fabric mod that adds gradient colors to your chat messages.

## Features

- Automatically applies gradient colors to outgoing chat messages
- 5 customizable gradient presets
- User-friendly GUI for editing presets
- Live preview of gradient effects
- Per-character hex color formatting

## Usage

1. Press **Right Shift** to open the Gradient Chat GUI
2. Select a preset from the left side
3. Customize colors by clicking on the color buttons
4. Type a message in chat and send it - the gradient will be applied automatically!

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.15.0+
- Fabric API
- Java 21

## Installation

1. Install Fabric Loader for Minecraft 1.21.1
2. Download the Gradient Chat mod JAR file
3. Place the JAR file in your Minecraft mods folder
4. Launch Minecraft with Fabric

## Building from Source

1. Clone this repository
2. Run `./gradlew build` (or `gradlew.bat build` on Windows)
3. Find the built JAR file in `build/libs/`
